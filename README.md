# Francois Mulongoyi Personal Training Website

A simple, modern fitness landing page for a mobile personal trainer. The site promotes personal training services, pricing packages, and a WhatsApp booking form for quick client enquiries.

## Overview

This project is a single-page website built with HTML and CSS. It includes:

- a strong hero section
- service highlights
- pricing plans
- booking form
- WhatsApp contact button
- mobile-friendly responsive layout

## Files

- `Fitweb.html` — main page structure and embedded styling
- `styles.css` — stylesheet file for page styling
- `gymfit.jpeg` — background/hero image used in the page

## Features

- Clean dark theme with green accent colours
- Responsive layout for desktop and mobile
- CTA buttons for booking and enquiry
- Pricing cards with clear package information
- WhatsApp integration for direct communication

## How to use

1. Open `Fitweb.html` in a browser.
2. If you want to update styling, edit `styles.css`.
3. Replace placeholder details such as name, phone number, pricing, and location with your own business information.

## Customisation

You may want to update the following:

- Trainer name and title
- WhatsApp number in the contact button and form
- Pricing values
- Business location
- Fitness goals and services offered

## Contact

For bookings or enquiries, use the WhatsApp button on the page to contact the trainer directly.
